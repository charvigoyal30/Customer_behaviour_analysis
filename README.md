# Customer_behaviour_analysis
Data Analytics Project
OVERVIEW

This project focuses on end-to-end data analytics using Python, PostgreSQL, and Power BI.
The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard creation, and reporting to generate meaningful business insights from the dataset.

The project demonstrates practical skills in:

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
SQL querying and database management
Data visualization
Dashboard development
Business reporting and presentation
Dataset

The dataset used in this project contains structured data for analytical purposes.
